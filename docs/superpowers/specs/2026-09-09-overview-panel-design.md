# 对比结果概览卡设计规格

> 日期：2026-09-09
> 状态：已获用户批准

## 目标

在「比对结果」页顶部增加概览卡：全局指标 + 每对文件卡片，让用户一屏看懂所有文件对的变动概况，并可点击卡片联动明细列表与网格，弥补当前只有明细列表 + 一行汇总文字、缺乏整体感的问题。

## 范围

- 仅新增概览展示层与配套计算逻辑，**不改动比对引擎、网格渲染、导出、数据结构**。
- 不新增持久化设置。

## 需求

1. 「比对结果」页顶部（DiffList 上方）新增概览区域，包含：
   - **全局指标条**：配对文件数、变动合计、未参与文件数（未参与数下方小字列出未参与文件名）。
   - **文件对卡片**（横向排列、超出换行），每对文件一张：
     - 文件名（截断显示，悬停展示完整文件名）
     - 变动数 + "处变动"（大号数字）
     - 五类变动构成条（增长/下降/从零新增/新增/移除，占比条）
     - 底部一行：「匹配 X/Y 工作表 · 峰值 ±NN%」
   - 当前文件对卡片呈选中态（蓝色描边）。
2. 点击卡片联动：
   - 明细列表（DiffList）筛选到该文件对；
   - 提供「全部」按钮恢复全量。
   - 网格高亮的文件对切换与选中索引一致（共用 `activePairIndex`，无需额外改动）。
3. 边界情况：
   - 0 变动的文件对：卡片灰调，构成条隐藏，显示「无变动」。
   - 未比对 / 无结果时：概览区域不渲染。

## 实现边界

- 新增 `src/shared/core/summary.ts`：纯函数汇总 `BatchCompareResult` → 每对文件汇总（五类计数、匹配工作表数、峰值变动率标签、未参与列表）。零 Node/Electron 依赖，可直接 vitest 测试。
- 新增 `src/renderer/src/components/OverviewPanel.vue`：全局指标条 + 文件对卡 + 点击联动。
- 修改 `src/renderer/src/App.vue`：比对结果标签页内，OverviewPanel 置于 DiffList 上方。
- 修改 `src/renderer/src/stores/session.ts`：提供「选中某文件对 / 显示全部」的状态切换动作（复用/调整 `activePairIndex` 与 `pairFilter`）。
- 修改 `src/renderer/src/components/DiffList.vue`：`pairFilter` 与概览卡选中态联动（点卡片筛选，点「全部」清除）。
- 配色沿用现有语义：红=增长、绿=下降、橙=从零新增、紫=新增、灰=移除；选中态蓝色描边。
- 导出（zip/HTML）、网格、比对引擎不变。

## 验证标准

- 单测覆盖 `summary.ts`：多对文件计数、五类统计、0 变动、未参与列表、峰值标签。
- 手动验证：比对样例后概览卡显示正确，点击卡片明细过滤、点「全部」恢复，网格文件对切换与卡片选中一致。
- 现有测试套件 + typecheck + production build 通过。
